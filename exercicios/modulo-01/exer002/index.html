Você pode escrever um parágrafo de qualquer jeito. Basta colocar tudo no meio do par de tags <p> e </p>

Se precisar quebrar o texto em algum lugar específico
como esse, você pode usar a tag <br>

HTML Entities

Não é possível a impressão de alguns símbolos no navegador, mas graças a HTML entities consiguiremos imprimir os mesmos símbolos como:

®: Marca Registrada
©: Copyright
™: Trade Mark
€: Euro
¢: Centimo
∑: Soma
E muito mais.

Inserindo Emojis

Também podemos adicionar emojis as nossas páginas web. Cada emoji possui um código único.
Para mas informações podemos acessar o site emojipedia.org.
