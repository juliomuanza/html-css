Para criar links em HTML usa-se a tag <a> </a>
Possuí quatro parâmetros, que são:

  • href - para indicar o caminho ou URL
  • hreflang - para indicar o idioma da página
  • target - indica onde a nova pág. deve abrir
  • rel - indica o proprietário do link
