Formatação de Textos


Texto negrito, itálico e Marcação

Negrito

Para negritar um texto usa-se a tag <strong> </strong>

Itálico

Para dar enface no texto usa-se a tag <em> </em>

Marcação

Para marcação de texto em HTML5 usa-se a tag <mark> </mark>

Deletar, sublinhar

Deletar

Para deletar texto em HTML5 usa-se a tag <del> </del>

Sublinhar

Para sublinhar textos em HTML usa-se a tag <ins> </ins>

Citação

Para fazer citação no meio do parágafo usa-se a tag <q> </q>

No caso de citação de um parágrafo inteiro usa-se a tag <blockquote> </blockquote>

Texto subrescrito e subscrito

Subrecritor

Para subrecrever texto como H2O usa-se a tag <sub> </sub>

Subscrito

Para subscriver o texto como X2+3X4 usa-se a tag <sup> </sup>

Abreviações

Para criar abreviações em HTML usa-se a tag <abbr> </abbr>

Techos de Códigos

Para incluir trechos de códigos utilizamos as tag <code> </code> para apresentação do código monospace. E a tag <pre> </pre> para deixar o texto pré-formatado com as suas propriedades.
