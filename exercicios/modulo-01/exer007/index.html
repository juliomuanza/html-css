A tag <ol> </ol> possuí dois parâmetros, o type e o start.
O type serve para informar o tipo de marcado.
O start serve para informar o ínicio da contagem.

tipos de marcadores

  1. 1 - para contagem numerica;
  2. A - para contagem alfabetica maiúscula;
  3. a - para contagem alfabetica minúscula;
  4. I - para contagem numerica romana maiúscula;
  5. i - para contagem numerica romana minúscula;
